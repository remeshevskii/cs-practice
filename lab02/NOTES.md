1. Рабочая папка - это локальное хранилище в котором находятся файлы, программы и тд.
Индекс - это  промежуточная память в компьютере, которая хранит изменений.
Коммит - это  снимок состояния проекта, зафиксированный в определённый момент времени.

2. Git - это система контроля версий для отслеживания изменений в коде локально на компьютере. А  GitHub - это веб-хранилище для проектов использующих Git.
git diff - это команда вывода разницы между файлами в рабочей папке и состоянием этих файлов в индексе. А git diff --staged - это команда вывода разницы между состоянием файлов в индексе и в последнем коммите.

3. Использование комманды.
Команда git status выводит состояния рабочей папки.
Команда git diff выводитразницу между файлами в рабочей папке и состоянием этих файлов в индексе.
Команда git diff --staged выводит разницу между состоянием файлов в индексе и в последнем коммите.

4. Ветки.
Ветка - это отдельная версия кодов проекта, в которой можно безопасно вносить изменения в код, при этом не ломая основной код.
При нвом коммите ветка автоматически сдвигается вперёд, указывая на этот новый коммит.
Слияние объединяет из одной ветки в другую, собирая результаты в один общий.
