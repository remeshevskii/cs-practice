1. Рабочая папка - это локальное хранилище в котором находятся файлы, программы и тд.
Индекс - это  промежуточная память в компьютере, которая хранит изменений.
Коммит - это  снимок состояния проекта, зафиксированный в определённый момент времени.

2. Git - это система контроля версий для отслеживания изменений в коде локально на компьютере. А  GitHub - это веб-хранилище для проектов использующих Git.
git diff - это команда вывода разницы между файлами в рабочей папке и состоянием этих файлами в индексе. А git diff --staged - это команда вывода разницы между состоянием файлов в индексе и в последнем коммите.
