Задание 2.
git diff - команда, которая выводит разницу между рабочей папкой и индексом.
git show - команда, которая ввыводит полную информацию о конкретном коммите (автора, дату, сообщение коммита и изменения, которые были внесены в этом коммите)
git log - команда, которая выводит историю коммитов.

Команда git log -S"def" ищет коммиты, в которых изменилось количество строк "def". Так как в calc.py мы не использовали эту функцию, то команда не нашла изменений.
Команда git  blame показывает построчную историю файла. Для каждой строки кода выводится полная информация о ней (автор, дата и коммит).



Задание 3.
Команда git restore берет версию файла из индекса, так как мы не делали перед этим git add, индекс совпадает с последним коммитом. Эта команда отменяет все незакоммиченные правки в рабочей папке.
Команда git restore --source=HEAD~2 lab03/calc.py берет версию файла из указанного коммита. Она заменяет файл на эту старую версию, но не меняет историю коммитов.
После выполнения команды git restore мои незакоммиченные правки бы исчезли, то есть файл бы вернулся к состоянию последнего коммита.
